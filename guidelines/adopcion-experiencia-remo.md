# Adopción de experiencia REMO

## Instrucción para repositorios

Incorporar este bloque en las instrucciones de desarrollo de cada proyecto REMO durante su siguiente intervención autorizada. Resolver primero cualquier conflicto con sus contratos de dominio y registrar la versión consultada del manual.

```text
Antes de diseñar, desarrollar o modificar una superficie REMO, consultar en
jurestrepo-wq/remo-brand-manual, rama main:
AGENTS.md, brand-engine.json, guidelines/estilo-de-escritura.md y
guidelines/experiencia-productos-informes.md.
Para toda presentación, leer además guidelines/presentaciones.md y aplicar
BRAND-PRESENTATIONS-1.0.0, con auditoría final obligatoria y registro por entrega.

Aplicar BRAND-EXPERIENCE-1.0.0: lo complejo lo hacemos simple.
Experiencia minimalista, intuitiva, visual y gamificada con guía opcional,
selección visual, progreso verificable y retroalimentación contextual.
Conservar rigor técnico y científico, validaciones, permisos, fuentes,
incertidumbre, unidades, metodología y profundidad mediante capas.

Usar skills pertinentes disponibles: digital-gamification para la guía;
impeccable para simplificar, aclarar, adaptar y tratar estados; skills de
explicación visual y de documentos/PDF para las entregas. Leer sus instrucciones.
Su mención no acredita disponibilidad ni instalación en este proyecto.

Todo resultado de negocio debe tener una entrega PDF legible, gráfica y
reproducible; añadir CSV/XLSX para datos tabulares cuando corresponda.
Preservar filtros, fecha de corte, fuentes, unidades, supuestos y totales.
Mantener concordancia entre pantalla, tablas y exportaciones.

Antes de aceptar, verificar tareas normales, vacías, parciales y errores;
accesibilidad, móvil, guía opcional, integridad numérica y PDF abierto e
inspeccionado. Reportar controles ejecutados, pendientes y límites reales.
Consultar además el release ACTIVE y las instrucciones específicas del proyecto.
```

## Registro por entrega

| Campo | Contenido |
|---|---|
| Superficie y tarea | Producto, usuario y objetivo concreto |
| Referencia | Commit del manual y versión de la norma |
| Mecánica | Guía, selección, exploración o checklist y su propósito |
| Capas | Resumen, análisis y evidencia |
| Exportación | Alcance PDF y archivos tabulares pertinentes |
| Concordancia | Estado de datos y comparación de resultados |
| Validación | Pruebas y revisión visual realmente ejecutadas |
| Pendientes | Incumplimiento, impacto y siguiente acción |

Actualizar esta evidencia con cada modificación de la superficie. La conformidad se declara por entrega verificada, sin asumir que todos los productos heredaron la norma al publicarla.
